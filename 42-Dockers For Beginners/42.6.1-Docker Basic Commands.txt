Then getting Started :-

docker run -d -p 80:80 docker/getting-started


-d is used for detached mode
-p is used for assign the port or map port from our local host
Host port and Container port are different
80:80
first is Host port
second is Container Port


For check our Docker is working or not we use "docker ps "
Is used for to check whether the Container is working or Not

* First check the status using "docker ps"
* Then type "docker stop {CONTAINER ID}"
* Now again type "docker ps" then you can see Container is stoped

Using "docker rm -f {IMAGE ID}" we can easily remove image from Container 

Now using "docker images" you can see the image is no longer exist in the container

Using "docker run {Image Name}" with the help of run command if the image is not present in container then it will pull the image from Docker Hub automatically then run
