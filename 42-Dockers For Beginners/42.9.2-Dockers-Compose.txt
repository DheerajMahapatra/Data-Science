## NOTE
If you make changes to your code (or Dockerfile), you must re-run
"docker compose up" (or "docker compose up --build") for those changes
to be reflected. Simply saving the file does NOT update the running
container — Docker builds an image from a snapshot of the code, so it
needs to rebuild that image to pick up the new changes.
