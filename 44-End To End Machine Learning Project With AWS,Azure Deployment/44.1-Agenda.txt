	it will install all the dependencies and create a folder {mlproject.egg-info}

	The mlproject.egg-info folder contains metadata about your Python project that is generated when you install/package it.

	In simple words:
	mlproject.egg-info tells Python/pip information about your project and its dependencies.

	For example, it may contain:
	PKG-INFO → project name, version, author, description
	requires.txt → required libraries
	top_level.txt → package names
	dependency_links.txt → dependency information
	SOURCES.txt → files included in the package




	-e = editable
	. = current project
	-e . = install my current project, but keep it connected to my source code.
	-e . → make your local ML project importable and editable during development.

	It makes your own project available as a Python package while you are developing it.

	your project gets installed in the environment, so Python can find mlproject.

	And because it is editable, when you change your code, Python uses the changed code immediately—you don't have to reinstall every time.


	In your ML project

	You have:

	src/
	└── mlproject/
		├── components/
		├── pipeline/
		└── utils.py

	You put:

	-e .

	in requirements.txt.

	Then:

	pip install -r requirements.txt

	installs your project itself.
